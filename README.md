# SINTES Psicología

Landing page separada en HTML, CSS y JavaScript.

## Estructura

- `index.html`: contenido y estructura.
- `css/styles.css`: estilos, variables, responsive y efectos.
- `js/script.js`: punto de entrada para futuras interacciones JavaScript.
- `assets/logo.jpg`: logotipo extraído del HTML original.

## Uso

Abre `index.html` en un navegador. No necesita proceso de compilación ni dependencias.

Nota: el HTML original no contenía bloques JavaScript ni eventos inline; por eso `js/script.js` queda preparado, sin añadir comportamiento nuevo.
